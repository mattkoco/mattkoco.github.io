## Start here

    ls -l                  # what's in ~
    cat about.txt
    cd projects && ls
    tree
    grep -ri "ctf" .
    contrib                # GitHub activity, in the terminal
    theme tokyo night      # or click the palette, bottom right
    blog                   # CTF writeups and notes
    help                   # everything else

Pipes, redirects, variables, globs, loops, functions and
scripts all work. Anything you create or delete lives in
memory and resets when you reload the page.
